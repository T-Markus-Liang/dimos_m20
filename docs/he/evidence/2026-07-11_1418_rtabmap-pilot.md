## Tuned RGB-D Odometry

Configuration uses `approx_sync=true` and
`approx_sync_max_interval=0.02`. In the untuned run, RTAB-Map accepted RGB/depth
pairs 53-73ms apart and reported delays up to about 0.37s. The 20ms gate
removed all bad-pair warnings.

## Mapping Pilot

The bounded 2Hz SLAM backend published:

- `/he/visual_occupancy` (`nav_msgs/OccupancyGrid`), initially 82x59 at 0.05m;
- `/he/visual_cloud_map`;
- `/he/visual_map_data`;
- `/he/visual_slam_info`;
- a 3.9-4.3MiB RTAB-Map database after a short static run.

With both TF publishers enabled, the isolated
`he_map -> he_visual_odom -> base_link` chain was continuous and both missing
TF and bad RGB/depth pairing warnings were zero. The first map sample proves an
output contract, not map quality; known/free/occupied content and TF continuity
are measured by `benchmark-he-visual-map.py` in the next run.
